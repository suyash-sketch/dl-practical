Experiment 1:

Aim: Implement the Multilayer Perceptron algorithm to simulate XOR gate.

Objectives:

  • To understand the working of a Multilayer Perceptron (MLP).
  • To implement MLP using backpropagation.
  • To simulate the XOR gate and predict its outputs correctly.

Theory:

A Multilayer Perceptron (MLP) is a feedforward neural network consisting of input, hidden, and output layers. It uses activation functions such as sigmoid and learns through backpropagation. MLP can simulate the XOR gate because its hidden layer can learn non-linear relationships that a single-layer perceptron cannot.

Algorithm:

1. Initialize weights and biases randomly.

2. Define the XOR input and output dataset.

3. Perform forward propagation through the hidden and output layers.

4. Calculate the prediction error.

5. Apply backpropagation to update weights and biases.

6. Repeat until the error is minimized.

7. Test the trained network with all XOR inputs.

Conclusion:

The MLP was successfully implemented using backpropagation and correctly simulated the XOR gate for all input combinations.


          import numpy as np

          # XOR input and target output
          X = np.array([[0, 0],[0, 1],[1, 0],[1, 1]])

          y = np.array([[0],[1],[1],[0]])

          # Set random seed for reproducibility
          np.random.seed(42)

          # Network architecture: 2 input neurons, 4 hidden neurons, 1 output neuron
          input_neurons = 2
          hidden_neurons = 4
          output_neurons = 1

          # Initialize weights and biases
          W1 = np.random.randn(input_neurons, hidden_neurons)
          b1 = np.zeros((1, hidden_neurons))

          W2 = np.random.randn(hidden_neurons, output_neurons)
          b2 = np.zeros((1, output_neurons))

          # Sigmoid activation function
          def sigmoid(x):
          return 1 / (1 + np.exp(-x))

          # Derivative of sigmoid using its output
          def sigmoid_derivative(x):
          return x * (1 - x)

          # Training parameters
          learning_rate = 0.5
          epochs = 20000

          # Train the neural network
          for epoch in range(epochs):

          # Forward propagation
          hidden_input = np.dot(X, W1) + b1
          hidden_output = sigmoid(hidden_input)

          final_input = np.dot(hidden_output, W2) + b2
          predicted_output = sigmoid(final_input)

          # Calculate error
          error = y - predicted_output

          # Backpropagation: output layer
          d_output = error * sigmoid_derivative(predicted_output)

          # Backpropagation: hidden layer
          hidden_error = np.dot(d_output, W2.T)
          d_hidden = hidden_error * sigmoid_derivative(hidden_output)

          # Update weights and biases
          W2 += learning_rate * np.dot(hidden_output.T, d_output)
          b2 += learning_rate * np.sum(d_output, axis=0, keepdims=True)

          W1 += learning_rate * np.dot(X.T, d_hidden)
          b1 += learning_rate * np.sum(d_hidden, axis=0, keepdims=True)

          # Test the trained network
          print("XOR Gate Results:")
          print("-----------------")

          for i in range(len(X)):
          hidden_output = sigmoid(np.dot(X[i:i+1], W1) + b1)
          output = sigmoid(np.dot(hidden_output, W2) + b2)

          result = 1 if output[0, 0] >= 0.5 else 0

          print(
          f"Input: {X[i]} | "
          f"Predicted: {output[0, 0]:.4f} | "
          f"XOR Output: {result}"
          )

Aim: Apply Stochastic Gradient Descent algorithm to learn the parameters of the

supervised single-layer feed-forward neural network.

Objectives

  • To understand Stochastic Gradient Descent (SGD).
  • To implement a single-layer feed-forward neural network.
  • To update weights after processing each training sample.
  • To minimize loss during training.

Theory

Stochastic Gradient Descent (SGD) is an optimization algorithm that updates the network's weights and biases after processing each individual training sample. It enables frequent updates and can converge quickly, but its updates may be noisy and less stable than batch-based methods.

Algorithm

  • Load and normalize the supervised dataset.
  • Split the data into training and testing sets.
  • Initialize weights and bias.
  • Perform forward propagation for one training sample.
  • Calculate the prediction error and gradients.
  • Update weights and bias using the learning rate.
  • Repeat for all samples over multiple epochs.
  • Evaluate the model's accuracy.

Conclusion

Stochastic Gradient Descent was implemented to optimize the parameters of a single-layer feed-forward neural network by updating weights after each training sample.

import numpy as np
from sklearn.datasets import make_classification
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import SGDClassifier
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score

# Generate dataset
X, y = make_classification(n_samples=100, n_features=4, n_classes=2, random_state=42)

# Split dataset into training and testing sets

Aim: Apply Mini Batch Gradient Descent algorithm to learn the parameters of the

supervised single-layer feed-forward neural network.

Objectives

  • To understand Mini-Batch Gradient Descent.
  • To implement a single-layer feed-forward neural network.
  • To update weights using small batches of training samples.

Theory

Mini-Batch Gradient Descent divides the training dataset into small batches and updates the model's weights after processing each batch. It provides more stable convergence than Stochastic Gradient Descent and improves computational efficiency.

Algorithm

1. Load and normalize the dataset.

2. Split the data into training and testing sets.

3. Initialize weights and bias.

4. Divide training data into mini-batches.

5. Perform forward propagation and calculate loss for each batch.

6. Compute gradients and update weights and bias.

7. Repeat for multiple epochs.

8. Evaluate the model's performance.

Conclusion

Mini-Batch Gradient Descent was implemented to update network parameters using small batches, enabling efficient training and stable convergence.

import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_classification
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import SGDClassifier
from sklearn.metrics import accuracy_score

# Generate data
X, y = make_classification(n_samples=100, n_features=4, n_classes=2, random_state=42)

# Plot data
plt.scatter(X[:, 0], X[:, 1], c=y, cmap='bwr', edgecolors='k')
plt.title("Classification Dataset")
plt.show()

# Normalize data
X = StandardScaler().fit_transform(X)

# Mini-batch SGD
model = SGDClassifier(loss='log_loss', learning_rate='constant', eta0=0.05, random_state=42)

batch_size, epochs = 16, 20

for epoch in range(epochs):
    idx = np.random.permutation(len(X))
    for i in range(0, len(X), batch_size):
        batch = idx[i:i + batch_size]
        model.partial_fit(X[batch], y[batch], classes=np.array([0, 1]))

    if (epoch + 1) % 2 == 0 or epoch == 0:
        print(f"Epoch {epoch+1}/{epochs} completed")

print('Learned Weights: ', model.coef_)
print('Learned Bias: ', model.intercept_)

Objectives

Theory

An autoencoder is an unsupervised neural network consisting of an encoder and a decoder. The encoder compresses an image into a smaller latent representation, while the decoder reconstructs the image. ReLU is used in hidden layers, sigmoid in the output layer, and Mean Squared Error (MSE) measures reconstruction loss.

Algorithm

  • Import libraries and load the MNIST dataset.
  • Normalize pixel values to the range \([0,1]\).
  • Reshape images into vectors.
  • Build the encoder, bottleneck, and decoder.
  • Compile the model using Adam optimizer and MSE loss.
  • Train using input images as both inputs and targets.
  • Display and compare original and reconstructed images.
  • Evaluate reconstruction loss.

Conclusion

The autoencoder was implemented for image compression and successfully learned compact image representations to reconstruct the original images.

import numpy as np
import matplotlib.pyplot as plt
from tensorflow.keras.models import Model
from tensorflow.keras.layers import Dense, Input
from tensorflow.keras.datasets import mnist

X_train = X_train.reshape(-1, 784) / 255.0

eng = ["hello how are you", "deep learning is great",

src_vec.adapt(eng)

trg_vocab = len(trg_vec.get_vocabulary())

import numpy as np

from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import GRU, Dense

# Generate sine wave data
series = np.sin(np.linspace(0, 30, 500))
LOOKBACK = 10

# Create sequences
X, y = [], []
for i in range(len(series) - LOOKBACK):
    X.append(series[i:i+LOOKBACK])
    y.append(series[i+LOOKBACK])

import numpy as np
from tensorflow.keras.preprocessing.text import Tokenizer
from tensorflow.keras.utils import pad_sequences
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Embedding, SimpleRNN, Dense, TimeDistributed

X = ["i like cats", "i like dogs", "you like cats"]
Y = ["i love cats", "i love dogs", "you love cats"]

tok = Tokenizer()
tok.fit_on_texts(X + Y)
x = pad_sequences(tok.texts_to_sequences(X), padding='post')
y = pad_sequences(tok.texts_to_sequences(Y), padding='post')

model = Sequential([
    Embedding(len(tok.word_index)+1, 8, mask_zero=True),
    SimpleRNN(16, return_sequences=True),
    TimeDistributed(Dense(len(tok.word_index)+1, activation='softmax'))
])

model.compile(optimizer='adam', loss='sparse_categorical_crossentropy')
model.fit(x, np.expand_dims(y, -1), epochs=200, verbose=0)

pred = model.predict(x, verbose=0).argmax(axis=-1)
for seq in pred:
    print(" ".join(tok.index_word.get(i, "") for i in seq if i))
