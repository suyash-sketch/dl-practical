Experiment 1:

Aim: Implement the Multilayer Perceptron algorithm to simulate XOR gate.

Objectives:

  • To understand the working of a Multilayer Perceptron (MLP).
  • To implement MLP using backpropagation.
  • To simulate the XOR gate and predict its outputs correctly.

Theory:

A Multilayer Perceptron (MLP) is a feedforward neural network consisting of input, hidden, and output layers. It uses activation functions such as sigmoid and learns through backpropagation. MLP can simulate the XOR gate because its hidden layer can learn non-linear relationships that a single-layer perceptron cannot.

Algorithm:

1. Initialize weights and biases randomly.

2. Define the XOR input and output dataset.

3. Perform forward propagation through the hidden and output layers.

4. Calculate the prediction error.

5. Apply backpropagation to update weights and biases.

6. Repeat until the error is minimized.

7. Test the trained network with all XOR inputs.

Conclusion:

The MLP was successfully implemented using backpropagation and correctly simulated the XOR gate for all input combinations.

  • Perform forward propagation for one training sample.
  • Calculate the prediction error and gradients.
  • Update weights and bias using the learning rate.
  • Repeat for all samples over multiple epochs.
  • Evaluate the model's accuracy.

Conclusion

Stochastic Gradient Descent was implemented to optimize the parameters of a single-layer feed-forward neural network by updating weights after each training sample.

  • Compile the model using Adam optimizer and MSE loss.
  • Train using input images as both inputs and targets.
  • Display and compare original and reconstructed images.
  • Evaluate reconstruction loss.

Objectives

  • To understand the architecture and working of an LSTM network.
  • To learn how LSTMs handle sequential data and long-term dependencies.
  • To prepare sequential datasets and train an LSTM model.
  • To evaluate model performance using suitable metrics.

Theory

Long Short-Term Memory (LSTM) is a type of Recurrent Neural Network (RNN) designed to learn long-term dependencies in sequential data. It overcomes the vanishing-gradient problem using a memory cell and three gates: forget, input, and output. These gates control which information is discarded, stored, and passed forward. LSTMs are used in handwriting recognition, speech recognition, machine translation, and time-series forecasting.

Algorithm

  • Collect and preprocess the sequential dataset.
  • Create input sequences and split the data into training, validation, and testing sets.
  • Initialize the LSTM network and its hidden and cell states.
  • Process each time step using the forget, input, and output gates.
  • Generate predictions and calculate the loss.
  • Apply backpropagation through time to update weights.
  • Repeat training until convergence.
  • Evaluate the model and compare predictions with actual outputs.

Conclusion

The LSTM model was designed to learn sequential patterns and long-term dependencies, enabling predictions for sequence-based applications.

Theory

A Recurrent Neural Network (RNN) is designed to process sequential data by maintaining a hidden state that carries information from previous time steps. At each time step, it processes the current input and previous hidden state to generate a new hidden state. RNNs are useful for temporal data classification because they learn patterns across sequences. They are trained using Backpropagation Through Time (BPTT), but may suffer from the vanishing-gradient problem.
